# 吹氣球 · WILD AIR CLUB (v6)

第三人稱 2D 街機小遊戲，繁體中文介面。深藍街機外框、青色遊戲場、螢光綠與粉紅操作台。無框架、無外部套件、無遠端素材，可離線執行。

[立即遊玩 / GitHub Pages](https://druidcub.github.io/balloon_game/) · [原始碼](https://github.com/druidcub/balloon_game) · [MIT License](LICENSE) · [第三方音效授權](THIRD_PARTY_NOTICES.md)

## PWA 與 GitHub Pages

線上版支援 PWA。首次連線開啟並完成快取後，可透過瀏覽器「安裝／加入主畫面」獨立開啟與離線遊玩；支援安裝提示的瀏覽器也會顯示「安裝遊戲」。新版本準備好時會出現「更新版本」，由玩家決定何時重新載入，不會在飛行中自行刷新。

Manifest、圖示與 Service Worker 都使用相對路徑，支援 GitHub Pages 的 `/balloon_game/` 子路徑。每次推送 `main` 後，`.github/workflows/pages.yml` 執行遊戲、音效、PWA 測試，產生 `_site` 並部署 Pages；只發布遊戲所需檔案。建置依內容雜湊產生離線快取版本，不需手動改版號。

本機建置：`node build.cjs`。預覽建置版：PowerShell 執行 `$env:SITE_DIR='_site'; node server.cjs`。檢查：`node tests.cjs`、`node audio-tests.cjs`、`node pwa-tests.cjs`。無需安裝 npm 套件。

程式碼及原創圖示使用 MIT；第三方錄音及其 Base64 資料另依來源權利，詳見 THIRD_PARTY_NOTICES.md。圖示可用 Windows PowerShell 執行 `./create-icons.ps1` 重新產生。

## 開始遊戲

雙擊 `開始遊戲.cmd` 或使用現代瀏覽器開啟 `index.html`。

建議正式遊玩使用固定的本機網址，讓瀏覽器紀錄保持在相同來源：安裝 Node.js 後，在這個資料夾執行 `node server.cjs`，開啟 http://127.0.0.1:4189 。伺服器只監聽本機；按 Ctrl+C 關閉。不需 npm install。

## 玩法

- 右上角「設定」可切換單人／雙人競賽，並輸入兩位玩家代號（最多 12 字）。設定保留在本機；儲存設定會重新開始本次遊戲，完成過的紀錄保留。
- 雙人模式由玩家 1 先開始，兩人輪流各飛 5 次。每趟結算按「下一位」或 R 換人；等待者站在目前玩家左側，兩人的衣色與代號保持一致。爆裂與左側失敗均消耗一次、計 0 分；各自取單次最遠成功距離比較，非加總。飛行中不能用 R 跳過回合。十趟完成後顯示「獲勝者：代號」，獲勝角色舉手跳躍；同分顯示平手，按「再比一場」重開。競賽進度只保留在目前頁面，重新載入會開始新一場。
- 地面上的 BEST 旗標代表歷來最遠成功紀錄；最近 20 筆各以「第 n 次」標示該趟最遠水平位置，左側位置保留負號、失敗為灰色。相近標記分組排列以減少重疊，標記會隨鏡頭滾動。每趟有持續遞增的飛行編號，最佳紀錄另存快照，即使超過最近 20 筆仍保留 BEST。舊紀錄缺少最遠位置時依方向與距離推估；最佳舊紀錄方向無法還原時以右側距離顯示。清除紀錄會一併重設編號及標記。

- 按住空白鍵，或按住畫面「按住吹氣」，讓氣球變大。
- 一口氣約能吹 2 秒。耗盡後必須放開，約 0.95 秒補滿；也可提早放開吸氣。
- 氣球至少 8% 可以放飛；大約 3 口氣可充飽。50% 以下安全，超過後繼續吹氣會有逐漸增加的爆裂機率；可超量充到 150%。100% 不是硬上限。
- 按 X 或「噴！」放飛。氣球噴口自由偏轉，推力與旋轉互相影響；會突然改向、繞圈、往左飛、折返或回到起點附近，並非每次都會發生。容量影響噴氣時間。
- 放飛後受噴氣推力、轉動慣性、重力、空氣阻力與弱風影響。首次碰地立即停止、癱落並結算，不彈跳。
- 放飛後的移動與洩氣以 2 倍速同步推進，使用固定小步進維持原本路徑特性；飛行時間記錄實際經過秒數。鏡頭跟隨也同步加快，吹氣與吸氣速度保持原設定。
- 即時 HUD 顯示目前離起點的水平距離與左右方向，折返時數值會減少。結算顯示最遠水平離起點距離（max abs(x)）、最高高度、飛行秒數與落點；最遠距離不等於落點距離，也不等於累計航程。落點在起點左側判定失敗，途中轉彎但落在右側仍成功；方向判定使用未四捨五入的座標。按 R 或「再吹一顆」重新開始。飛行中按 R 會直接放棄該次，未完成的飛行不存檔。
- 右上角可關閉音效、查看紀錄。開啟紀錄或切換背景分頁時暫停。
- 手機／平板可直接長按吹氣與點擊放飛。

## 紀錄與聲音

使用 `localStorage` 的 `balloon-day.records.v1`，保留最近 20 次完整飛行，以及獨立的歷來最遠、最高紀錄。更舊的飛行被移除後，最佳成績仍保留。可在紀錄視窗中確認清除。儲存受限時會顯示提示並暫存於記憶體。不同瀏覽器、網址與通訊協定的紀錄不共用；直接開啟 file:// 的儲存行為由瀏覽器決定。

左側落地會標記為 `wrong-way`、播放本機合成的低音下降失落音效，並從六句失敗評語中隨機選句，不播放掌聲。其實際距離／高度仍保留在紀錄中，但不更新最佳成績。紀錄視窗的「最遠距離」與「最高高度」從最近 20 筆中的成功紀錄分別取 max，可來自不同趟，絕不累加；場景的 BEST RANGE 保留歷來成功最大值。舊紀錄首次套用 `scoringVersion:2` 時，依保留的有效成功紀錄重算，排除左側落點與不可信的舊最佳快取；更早已被裁掉的飛行無法恢復，但原本保留的紀錄不會刪除。後續保存的歷來最佳可持續超過 20 筆歷史。

Web Audio API 合成吹氣、爆音與備援氣流，並使用隨附 MP3 作氣球放氣、吸氣、罐頭笑聲、鼓掌、驚嘆與安可歡呼。氣球聲隨剩餘氣量改變播放速率與音高：氣多偏低、氣少偏高，同時保留噴口顫動。第一次按鍵或點擊後啟用聲音，沒有麥克風權限需求。所有音效皆可離線使用。素材署名與授權見 AUDIO-CREDITS.md，以及遊戲頁底部的「音效來源與授權」。

## v2 飛行研究與近似

舊模型將水平加速度限制在正向，並用小角度正弦波控制方向，因此無法真正折返。新版將推力拆成 cos(方向)、sin(方向) 兩個分量，方向不限制角度；不規則噴口偏移產生轉矩，角速度經慣性與阻尼累積，氣量逐漸降低推力，空氣阻力消耗動量。隨機擾動由每次發射的種子決定，物理仍以 120 Hz 固定步進，並非依畫面幀率抖動座標。

參考：Kim (2026), [Physically plausible balloon dynamics via position-based constraints and geodesic-weighted forces](https://doi.org/10.1371/journal.pone.0348597)。論文指出放氣反作用力與不對稱形變會引起不規則旋轉與複雜路徑。本遊戲採二維遊戲化近似，未實作該論文的完整 PBD 網格或流體／材料模擬，不作真實飛行距離預測。首次碰地就結束是本遊戲規則。

舊版 localStorage 紀錄原樣保留；新紀錄增加 landingX、pathLength、model 欄位，舊紀錄的落點顯示「舊版 —」。新舊模型成績難度不同，可自行決定是否在紀錄視窗清除舊成績。

## v3 爆裂與觀眾反應

- 50% 以下無爆裂風險。超過 50% 後，僅在實際吹氣時累計風險；放開吸氣時不判定，重新按下也不會重設已累積的風險。
- 持續吹氣的瞬時爆裂率 λ = -ln(0.45) × ((氣量 - 0.50) / 0.50)²；顯示的每秒機率為 1 - exp(-λ)，對應目前氣量保持不變時再吹一秒的近似機率。實際吹氣會繼續增加氣量，所以後續風險更高。
- 約 60% 時每秒 3%，75% 時每秒 18%，100% 時每秒 55%，120% 時每秒 79%，150% 時每秒 96%。超過 100% 的每秒爆裂機率必定高於 50%。上限 150% 仍持續承受吹氣風險與消耗肺活量，不會因達上限而安全。
- 氣球爆裂立即停止進氣，播放爆音與約 3.8 秒觀眾笑聲，展示短暫碎片動畫，再以 0 m / 0 m 高度 / 0 秒記錄為 burst。原最佳成績不被降低。
- 正常落地以最遠水平離起點距離判定獎勵：低於 5 m 為短掌聲；5–15 m 為較熱烈掌聲；15–30 m 為驚嘆加掌聲；30 m 以上為安可觀眾歡呼加掌聲。
- 「音效試聽」可單獨試聽漏氣、笑聲、掌聲、驚嘆與安可；氣量滑桿只改試聽音高，不影響實際遊戲。
- 靜音會停止觀眾聲，重新開始會中斷上一局反應。切換背景頁面或開啟紀錄時停止音效，飛行與進氣規則維持原設定。

新增 sound.js 管理音效、audio-assets.js 提供 Base64 離線音效包、assets/audio 保留可替換 MP3、pack-audio.cjs 重新打包音效。更新本機伺服器後需關閉舊伺服器再重新啟動，因為新版本增加了可提供的音效與腳本檔案。

## v4 噴流、轉動與阻力的統一模型

- `heading` 表示球身朝向，`flutter` 是小幅噴口偏轉。物理與畫面共用同一個噴口方向；畫面球身旋轉為 -heading、噴口局部旋轉為 -flutter。出氣向量與推力向量永遠相反。
- 剩餘氣量 V 對應的遊戲壓力近似為 P = V^1.15，流量與噴速均正比於 sqrt(P)，因此推力正比於流量 × 噴速。這是為玩法採用的單調近似，未宣稱是真實乳膠氣球的壓力曲線。
- 氣流僅產生小幅噴口偏移與受力偏心；轉矩隨推力與力臂增加，角加速度再除以轉動慣量，並扣除旋轉空氣阻尼。氣排光後不再額外注入隨機轉矩。
- 半徑按體積的立方根變化，迎風面積按半徑平方變化。阻力與迎風面積及相對風速的平方成正比，方向與相對風速相反；滿氣球的阻力大於小氣球。氣球視覺尺寸也使用相同的立方根縮放。
- 起飛由噴氣推力從靜止加速，取消固定的初速。轉向後仍保留動量，反向推力會先煞車，再改變速度，並非瞬間改寫速度方向。
- 方向輔助與箭頭已從畫面移除；白色噴流仍從正確的出氣口向外噴出。
- 紀錄模型標記為 jet-coupled-v4；舊紀錄繼續保留。

依據：[NASA Rocket Principles](https://www.grc.nasa.gov/www/k-12/rocket/TRCRocket/rocket_principles)、[NASA Rocket Thrust Equation](https://www1.grc.nasa.gov/beginners-guide-to-aeronautics/rocket-thrust-equation/)、[NASA Drag Equation](https://www1.grc.nasa.gov/beginners-guide-to-aeronautics/drag-equation/)。目前仍是採用標準力學關係的二維遊戲近似，不是真實流體與乳膠材料模擬。

## v5 低氣量飛行平衡

低氣量的壓力近似改為 P = V^0.8，讓未吹飽的氣球也有足夠推力離地。阻力係數由 0.022 + 0.12A 改為 0.022 + 0.09A（A 為相對迎風面積），耗氣係數由 0.30 改為 0.24，以平衡隨推力增強而提高的流量。推力仍與噴流反向，轉矩仍為力臂與反作用力的叉積；迎風面積與速度平方的阻力關係、50% 安全區、爆裂機率與獎勵分級皆保留。

使用 200 個固定種子（0/200 至 199/200）比較最遠水平距離的平均值：20% 氣量由 1.8 m 提升至 8.3 m；30% 由 5.9 m 至 18.8 m；40% 由 13.5 m 至 25.2 m；50% 由 19.4 m 至 28.5 m；100% 由 27.3 m 至 33.8 m。這是遊戲模擬的平均值，每次航線仍不同。

## v6 不規則噴流與旋轉

- 平移阻力係數調整為 0.018 + 0.065A，相同球體大小與速度下比 v5 約減少 24–26%。面積與速度平方的關係保留。
- 噴口擾動間隔由 0.18–0.50 秒縮短為 0.09–0.35 秒，方向響應時間由 0.12 秒縮短為 0.055 秒。
- 一般噴口偏轉與偏心幅度增大；每次擾動有 32% 機率出現約 1.8 倍的短暫噴口彎折，另有 0.8–1.2 倍的流量脈動。這是噴口擾動事件的機率，並非氣球爆裂機率。
- 旋轉空氣阻尼略降低，讓氣球有較明顯的盤旋與翻轉；所有轉動仍由噴氣的力臂與推力產生，推力仍與畫面噴口方向相反，排空後不增加隨機轉矩。
- 以同樣 200 個種子比較：40% 氣量左右旋轉切換次數平均由 0.16 次提升至 0.59 次；100% 由 0.92 次至 1.41 次。20% 平均最遠距離約 7.6 m，40% 約 20.8 m，100% 約 27.4 m。航線更常彎回來，因此最遠距離不一定隨阻力降低而增加。

## 隨機結算評語

已加入 10 類、每類 6 句，共 60 句短評。評語詞庫與選句邏輯在 engine.js 的 COMMENT_POOLS、commentCategories 與 Commentator，結算時由 game.js 顯示；使用獨立隨機選句，不會改動既有飛行路徑。

- 飛很遠：最遠水平距離至少 30 m。
- 飛很高：最高高度至少 18 m；同時很遠很高時使用專用的雙成就評語。
- 失控：累計旋轉至少一圈、左右旋轉切換至少 2 次，或水平飛行方向切換至少 2 次，任一成立即可。旋轉與切換數由實際物理步進累計，採死區避免微抖動誤判。
- 繞回起點：曾離開至少 5 m，落點位於起點 3 m 內且不超過最遠距離的 20%。
- 低空巡航：最遠至少 15 m、最高不到 4 m。
- 短程落地：最遠不到 5 m；一般小旅行：5–15 m；中程旅遊：15–30 m，且未命中較特殊表現。
- 吹爆：只從爆裂評語選，不能誤用飛得高或飛得遠的評語。

同時命中多個特色時，從所有符合的類別中隨機選一句。本次頁面遊玩期間避免與上一局使用完全相同的評語。歷史紀錄保留 totalRotation、turnReversals、horizontalReversals 供未來擴充，但舊紀錄沒有這些欄位也能正常讀取。

例句：飛遠「再遠一點，就要開始算漫遊費了。」；飛高「飛到這個高度，雲都想問它有沒有預約。」；失控「這條航線，連畫它的虛線都暈了。」；返回「跑了一大圈，只為確認起點真的存在。」；短程「剛出發就下班，效率很有自己的想法。」；吹爆「本次航程：從期待到意外。」

## 角色與吸氣更新

方向輔助按鈕、推力／速度箭頭及其圖例已移除。角色以 Canvas 原生路徑重繪，額頭、鼻樑、鼻翼、嘴唇與下巴形成連續側臉，並加入眼眉、耳朵、頭髮、握住氣球的手指與衣服陰影；吹氣時微鼓頰並嘟嘴，補氣時嘴唇放鬆、眼睛張開，從鼻子前方顯示吸氣氣流。

補氣改用指定 YouTube 影片「急促的呼吸聲」3.74–4.30 秒的吸氣部分，保留原速；短補氣只裁短時長，一次補氣只啟動一次。重新吹氣、補滿、靜音或重新開始都會停止吸氣聲。所有素材保持離線打包，來源與剪輯方式見 AUDIO-CREDITS.md 和 audio-source-notes.json。

## 連續漏氣音高與參考素材

漏氣改用指定 Curious Eyes 影片 2.12–3.06 秒的實際錄音。sound.js 將 120 ms 片段以 Hann 包絡重疊、隨機錯開原錄音位置，建立 2 秒平滑循環，保留橡膠顫動與空氣摩擦；不再壓成單週期純音，也不循環整段降調錄音。取樣使用獨立固定種子，不影響遊戲物理亂數。

整趟飛行只有一個持續音源，氣量控制 0.86–1.04 倍播放速率，0.12 秒平滑銜接；使用 2600 Hz 低共振低通和適度音量，正常播放時關閉合成橡膠振盪層，保留錄音原本的自然起伏。落地、靜音、重置均停止；試聽使用相同處理。audio-tests.cjs 檢查接縫、波形與離線素材一致性、播放時機、音高連續性、停止與失落音效。
